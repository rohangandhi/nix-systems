# Icons

Five SVGs from [Lucide](https://lucide.dev), bundled locally under its
[license](LICENSE-Lucide). Upstream revision: `66d8f9fc394b8530377e5f6112f0b8908ba01280`.

| Local name | Upstream icon |
| --- | --- |
| graphics | cpu |
| memory | memory-stick |
| video | film |
| temperature | thermometer |
| power | zap |

Source: `https://github.com/lucide-icons/lucide/tree/66d8f9fc394b8530377e5f6112f0b8908ba01280/icons`.
The 24×24 viewBox and appearance of the 2-unit round strokes are preserved.
GNOME's symbolic renderer recolors fills, so strokes are expanded to equivalent
filled paths with Inkscape 1.4.4 (`select-all;object-stroke-to-path`). Editor
metadata is removed and each path uses the symbolic foreground marker `#2e3436`.
Files retain the `-symbolic.svg` suffix so Shell applies its active icon color.
No icon font, JavaScript library or runtime network access is required.
